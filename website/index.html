ADRs

Features

Everything a modern restaurant needs, nothing it doesn't.

🪑 Table Management

Visual floor plan, drag-to-move, merge/split, covers, server assignment, waitlist integration.

🍳 Kitchen Display System

Real-time ticket routing by station (grill/fry/salad), bump bars, prep timers, all-day view.

📦 Inventory Deduction

Recipe-based auto-deduction, par levels, waste tracking, vendor ordering, cost variance.

🌐 Online Pickup

Customer-facing ordering, time-slot selection, kitchen routing, SMS/email notifications.

💰 Payments

Cash, card (Stripe Terminal), split checks, tips, gift cards, house accounts.

📊 Reporting

Sales by category/server/hour, menu engineering (stars/dogs), labor %, prime cost.

Core Workflows

Dine-In Flow

1. Host seats party → Table 7 (4 tops)
2. Server opens table → Adds items
3. Order sent → Kitchen Display (Grill)
4. Cook bumps → "Ready" notification
5. Server delivers → Table updates
6. Guest pays → Split/tip/receipt
7. Table closes → Inventory deducted

Online Pickup Flow

1. Customer orders → Selects 12:30 slot
2. Order routed → Kitchen (Salad station)
3. Cook prepares → Marks ready
4. Customer arrives → QR check-in
5. Staff hands off → Marks collected
6. Inventory auto-deducted

Inventory Cycle

1. Morning par check → Low alerts
2. Vendor order placed → PO generated
3. Delivery received → Scan + verify
4. Put-away → Bin locations updated
5. Nightly variance → Cost report

Verified Gates

What works today, verified in staging.

  • ✅Table lifecycle: open → order → serve → pay → close
  • ✅Kitchen routing: by station, bump bars, timers
  • ✅Inventory deduction: recipe-based, real-time
  • ✅Online pickup: slot selection, SMS, handoff
  • ✅Split payments: cash/card/tip/gift card
  • ✅Reporting: sales, menu engineering, labor
  • ✅Staff roles: cashier/server/manager/admin
  • ✅Setup tokens: no default passwords

    • Architecture Decision Records

    ADR-001: Next.js 15 + Cloudflare Workers

    Same rationale as pos-retail. Edge compute for global latency.

    ADR-002: Kitchen Display as Separate Worker

    Isolate real-time WebSocket traffic from order API. Independent scaling.

    ADR-003: Inventory as Event Sourcing

    Every deduction = event. Full audit trail. Enables variance analysis.
